# hwpx-report-filler

raw/ 에 있는 세 가지 입력(템플릿, 내용파일, 엑셀)을 읽어 out/ 에 서식이 적용된 HWPX 보고서를 생성한다. 01_페인포인트.md·02_기획안.md에서 정의한 "서식을 손으로 맞추는 불편"을 없애는 것이 목적이다.

## 입력 (raw/)

1. **서식 템플릿** `.hwpx` — "문서 표준 양식.hwpx" 구조. 제목 자리에 "보고자료 제목"이라는 문구가 그대로 있는 파일로 자동 식별한다.
2. **내용파일** `.hwpx` — 서식은 무시하고 내용만 쓴 파일. 사람이 쓰는 만큼 형식이 정확히 안 맞을 수 있다 (라벨이 없거나, "ㅇ 배경 : 내용"처럼 한 줄에 같이 쓰거나, 날짜·참고자료가 없을 수도 있음). 그래서 Claude가 직접 읽고 판단한다 (아래 절차 2 참고).
3. **엑셀** `.xlsx` — 표에 들어갈 데이터 1개. 헤더 행은 "순번"이 적힌 행(없으면 첫 행)으로 자동 인식하고, "순번" 다음에 오는 열을 전부 표에 채운다(4개로 고정하지 않음 — 열이 몇 개든 그 개수만큼 표의 열이 늘어나거나 줄어들고, 표 전체 너비는 유지한 채 열 너비만 다시 균등하게 나눈다). 앞에 제목 행이나 순번 열이 있어도 없어도 동작한다.

raw/ 에 템플릿·엑셀이 정확히 1개씩 없으면(후보가 겹치거나 0개/2개 이상이면) 바로 멈추고 무엇이 모자라거나 겹치는지 알려준다 — 추측해서 진행하지 않는다.

## 절차

1. raw/ 에 템플릿·엑셀이 각 1개씩 있는지 확인한다 (`python scripts/generate_report.py` 를 인자 없이 실행하면 이 확인과 함께, 내용파일이 "ㅇ (배경)" 같은 템플릿 문구 + 다음 줄 형식을 정확히 따랐을 때는 이 한 번으로 끝까지 끝난다 — 그 형식에 맞으면 2~3단계를 건너뛰어도 된다).
2. 1번으로 바로 안 되면(형식이 자유롭게 쓰여 있으면), raw/ 의 내용파일을 직접 읽어 다음 형식으로 정리한다:
   - `title`: 제목
   - `date_org`: 날짜·기관 — 없으면 비워둬도 됨(오늘 날짜로 자동 채워짐)
   - 내용파일에는 `ㅁ`, `ㅇ`, `-`, `*` 네 단계 구분이 있을 수 있다("1. 개요", "2. 내용"처럼 숫자로 쓰기도 함). 순차적일 수도, 중간 단계가 생략될 수도 있다(예: `ㅇ` 다음에 `-` 없이 바로 `*`가 나올 수 있음) — 쓰여진 그대로 단계를 읽는다.
   - `overview_items`: "□ 추진 개요"(보통 배경·목적) 아래에 들어갈 줄들을 문서에 나오는 순서 그대로 나열. 각 줄은 `{"depth": 1|2|3, "label": "라벨(깊이1=ㅇ일 때만)", "text": "내용"}` (depth 1=ㅇ, 2=-, 3=*)
   - `main_items`: "□ 주요 내용" 아래에 들어갈 줄들, 같은 형식. 라벨은 "내용"으로 고정할 필요 없이 실제 내용에 맞게 자유롭게(예: "조사기간", "조사결과", "현황" 등) 정하고, 항목 수도 내용에 맞게 정한다.
   - `table_caption`: 표 제목 — 내용파일에 없으면 엑셀의 표 제목으로 보이는 셀을 참고해도 됨
   - `ref_title`: 참고자료 제목 — 내용파일에 참고 관련 언급이 전혀 없으면 빈 문자열로 둔다. 그러면 "참고1" 문단 전체가 출력에서 빠진다
   - 표 행 수는 자동으로 맞춰진다: 엑셀 데이터가 4개면 표도 4행(템플릿의 5·6번째 빈 행은 자동으로 사라짐), 10개면 10행까지 자동으로 늘어난다 — 별도로 신경 쓸 필요 없음
   - **내용을 지어내지 않는다.** 정말 모호하거나 빠진 항목(특히 날짜·참고자료)은 기본값으로 비워두지만, 그래도 애매하면 사용자에게 먼저 물어본다.
3. 2번에서 정리한 내용을 JSON 파일로 저장하고 다음을 실행한다 (설치 불필요, Python 표준 라이브러리만 사용):
   ```bash
   python scripts/generate_report.py <content.json 경로>
   ```
4. 출력된 `생성 완료: out/...` 경로를 사용자에게 알려준다. 2~3단계에서 직접 판단해 채운 항목(날짜 기본값 적용, 참고자료 생략 등)이 있다면 무엇을 어떻게 채웠는지 같이 알려준다.
5. **이 스킬은 생성된 파일을 실제로 열어 글꼴·표가 멀쩡한지 확인할 수 없다.** 사용자에게 out/ 의 결과 파일을 한글(HWP)에서 직접 열어 확인해달라고 안내한다 (01_페인포인트.md 검증 기준: 수동 수정 0분).

## 하지 않는 것

- raw/ 의 원본 파일 수정, out/ 외의 위치에 결과물 생성
- 서버·앱 설치, 외부 계정 연동, 외부로 파일 전송
- 이 템플릿 구조와 다른 HWPX 양식 처리, 엑셀-HWPX 대조, 자료 출처 탐색 (02_기획안.md 범위 밖)
